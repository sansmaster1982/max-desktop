# Компоненты и происхождение MAXIM

Этот файл относится к публичной редакции MAXIM `1.1.0-alpha.1`. Это экспериментальный независимый клиент, не официальный дистрибутив MAX.

## Ресурсы этой публичной редакции

* Используется собственный знак MAXIM — две реплики на тёмном фоне с лаймовым акцентом.
* Вместо извлечённых фонов включены семь простых геометрических SVG, подготовленных для этого выпуска. Палитры и размеры интерфейса описаны в коде.
* Звук уведомления синтезирован для этого выпуска; прежний MP3 из оригинального приложения не включён.
* Скопированные сборки JavaScript для звонков и видео исключены. Соответствующий путь выполнения отключён при отсутствии этих ресурсов.
* Полный каталог переводов, извлечённый из локализаций MAX, не распространяется. Публичная редакция использует собственные переводы клиентских фраз и отдельно составленный небольшой набор основных подписей. Непереведённая строка остаётся на русском языке.

Рабочие исследования, архивы веб-приложения, снимки экрана, файлы аккаунтов, кэш, `.local`, `.test-tmp` и журналы с пользовательскими данными не включаются в пакет.

## Библиотеки в Windows-сборке

Сборка использует Python, PySide6/Qt, shiboken6, msgpack, websocket-client, qrcode, requests и их зависимости, zstandard, а также компоненты, которые включены упаковщиком PyInstaller. Точные версии фиксируются в файле зависимостей сборки и её квитанции. PyInstaller не меняет лицензии включённых библиотек. QtWebEngine/Chromium и QtWebChannel исключены из portable EXE этой редакции; собственный исходный модуль мини-приложений сохранён для разработки.

Тексты лицензий и дополнительные сведения находятся в каталоге [third_party_licenses](third_party_licenses/). Сведения о Qt, WebEngine, Chromium, мультимедиа и источниках соответствующей версии приведены в [Qt_NOTICES.md](Qt_NOTICES.md). Исходная лицензия каждой библиотеки имеет приоритет над общим описанием здесь.

Qt/PySide6 имеет варианты лицензирования, включая LGPL. Публичная сборка должна содержать соответствующие уведомления и сохранять возможность замены динамически подключённых библиотек совместимыми версиями. Поэтому Windows-пакет выпускается как переносимая папка с `MAXIM.exe` и библиотеками, а не как единственный закрытый исполняемый файл. Не запрещается обратная разработка в объёме, необходимом для отладки изменений библиотек, распространяемых по LGPL.
